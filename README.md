# 小聆 MCP for Home Assistant

把 Home Assistant 接入小聆 AI 后，就可以用小聆设备通过语音控制家里的灯、开关、场景等。

一台 Home Assistant 可以关联多台小聆设备，每台设备单独配对、单独使用。

## 使用前准备

- 已安装并可以正常打开 Home Assistant
- 已安装 [HACS](https://hacs.xyz/)
- 手机上已安装小聆相关小程序，并能生成配对码
- 需要被小聆控制的设备，已在 Home Assistant 中添加好

建议先到 **设置 → 语音助手 → 公开**，把要给小聆控制的灯、开关、窗帘等实体公开出来。没有公开的设备，小聆一般无法控制。

## 安装插件

1. 打开 HACS。
2. 添加本仓库为自定义仓库，类别选择 **Integration**。
3. 搜索并下载 **MCP Server for xiaoling**。
4. 重启 Home Assistant。

HACS 只负责安装插件，安装完成后还需要在 Home Assistant 里手动添加集成。

## 添加集成

1. 打开 **设置 → 设备与服务**。
2. 点击右下角 **添加集成**。
3. 搜索 **小聆 MCP** 并添加。
4. 第一次添加时不需要输入配对码，这一步只是启用插件。

添加成功后，集成页面里还没有设备，需要继续配对。

## 配对小聆设备

1. 在小程序中生成配对码。配对码有效时间较短，请尽快在 Home Assistant 中使用。
2. 打开 **设置 → 设备与服务 → 小聆 MCP**。
3. 点击 **添加设备**。
4. 输入刚才的配对码并提交。

配对成功后，这台小聆会出现在该集成的设备列表中，并开始连接小聆服务。

如果提示配对码无效或过期，请回到小程序重新生成后再试。  
如果提示该设备已经关联，说明这台设备已经添加过，不必重复配对。  
如果提示绑定数量已达上限，请先在小程序中解除不需要的绑定，再重新配对。

## 添加更多设备

同一套 Home Assistant 可以继续添加其他小聆设备：

1. 再次进入 **小聆 MCP** 集成页面。
2. 点击 **添加设备**。
3. 输入另一台设备的配对码。

每台设备都需要单独配对。一台配对成功，不会自动带上其他设备。

## 日常使用

配对完成后，直接对小聆说话即可，例如：

- 打开客厅灯
- 关闭卧室空调
- 现在家里开着哪些灯

小聆能控制哪些设备，取决于你在 Home Assistant 语音助手里公开了哪些实体。如果某台设备叫不出来，先检查它是否已公开，以及名称是否容易识别。

## 管理设备

设备的重命名、禁用、删除，都可以使用 Home Assistant 自带的设备页面操作。

- **重命名**：只影响 Home Assistant 里显示的名称。
- **禁用**：暂时停用这台设备，不会删除配对记录。
- **删除设备**：只从当前 Home Assistant 中移除这台小聆，不会删除整个「小聆 MCP」集成，也不影响其他已配对设备。

如果以后不再使用某台设备，建议同时在小程序中解除绑定。

## 常见问题

**安装后找不到「小聆 MCP」？**  
先确认 HACS 已下载完成，然后重启 Home Assistant，并强制刷新浏览器后再搜索。

**添加集成后没有设备？**  
这是正常的。需要再到集成页面点击「添加设备」，并输入小程序里的配对码。

**配对失败？**  
常见原因是配对码过期、输错，或该设备已经添加过。请重新生成配对码后再试。

**小聆听懂了，但控制不了设备？**  
到 **设置 → 语音助手 → 公开** 检查对应实体是否已公开，并确认实体名称清楚、容易识别。

**重启 Home Assistant 后还要重新配对吗？**  
不用。已经配对成功的设备会在重启后自动重新连接。
